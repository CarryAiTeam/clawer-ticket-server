# 09 · 限流与导出恢复

每个 profile 使用独立串行请求队列和滑动窗口预算。默认最多每分钟 20 次；当本地预算已满时，adapter 会等待下一个可用窗口。

ONES 返回 429 时，adapter 优先使用 `Retry-After`；无有效头时才采用有界重试。调用方不应通过提高本地预算规避 ONES 服务端限制。

查询导出先完整枚举并冻结 selection。`write` 会重新枚举；总数变化、重复 ID、不完整分页或 selection 不匹配都会拒绝写入。

单张写入采用暂存目录、锁目录和原子提交。已有媒体用 manifest 的 SHA-256 校验：完整文件可复用，缺失或损坏文件会再次下载。`media:"metadata"` 不下载任何二进制文件。

V1 没有“我的待办批量导出”专用方法或按展示名称 `statuses` 续传语义；所有查询导出都通过 `ticket_export({ query, ... })`。
